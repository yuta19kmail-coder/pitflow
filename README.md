# PitFlow

整備工場の入庫予約・作業フロー管理アプリ。

兄貴分の **CarFlow**（中古車販売店向け）と並列で運用する想定。

## 構成

| ビュー | 役割 |
|---|---|
| 📅 予約 | 当日／週／月／2ヶ月の予約カレンダー |
| 📋 タスク | Trello風カンバン（点検待ち→見積り中→連絡中→パーツ待ち→作業待ち） |
| 🔧 作業 | PIT枠ごとに当日の作業順を可視化 |
| ✅ 実績 | 作業完了→返車完了→月次締め→アーカイブ |
| 🚙 代車 | 代車×日付のガントで貸出状況を把握 |

## 技術スタック

- HTML + CSS + vanilla JS（モック段階）
- 後で Firebase（Firestore / Auth / Storage / Hosting / Functions）に接続予定
- マルチテナント設計（`companies/{companyId}/` 配下）— CarFlowと同じ思想

## ローカル起動

```
# 本ディレクトリで
python -m http.server 8080
# → http://localhost:8080/
```

または `index.html` をそのままブラウザで開いてもOK。

## バージョン管理ルール（CarFlow流儀）

コードを書き換えたら必ず3箇所セットでバージョンを上げる：

1. ログイン画面の `vX.Y.Z` 表示（将来追加）
2. トップバー右の `vX.Y.Z` バッジ
3. 全 `?v=N` キャッシュバスター
